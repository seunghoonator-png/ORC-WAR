# ORC-WAR 그래픽 명세 — 절차 생성 스프라이트

> v0.2 · 2026-08-27 · **결정: 외부 애셋 조달 없이 전 그래픽을 코드로 생성한다.**
> (v0.1의 이미지 생성 프롬프트 방식은 폐기. 사용자가 만든 검방보병 일러스트는 UI 아이콘 후보로 보관.)

## 원칙

- 모든 스프라이트는 실행 시 코드가 16×16 캔버스에 도형으로 그려 아틀라스에 굽는다(외부 파일 0개 → 단일 exe에 유리).
- 기준은 심미성이 아니라 **식별성**: 인게임 실물 크기(12~16px)에서 병종이 구분되면 합격.
- 팀 구분은 몸통(튜닉/기수) 색: 적 `#C42820` / 청 `#2450BE`. 병종 구분은 실루엣 + 보조 색.
- 모든 유닛은 북쪽(위)을 향해 그리고, 엔진이 이동 방향으로 회전시킨다.

## 병종별 실루엣 규칙 (프로토타입 검증 완료)

| 병종 | 실루엣 열쇠 | 구성 |
|---|---|---|
| 검방보병 | 좌전방의 큰 원방패 | 팀색 몸통 + 나무색 원방패 + 우측 검 |
| 장창병 | 몸을 관통하는 세로 긴 창대 | 팀색 몸통 + 전신 길이 창 + 창날 |
| 중갑도끼병 | 유일한 **각진 강철 몸통** | 회색 사각 갑주 + 팀색 투구 + 우측 도끼 |
| 궁수 | 전방의 활 호(arc) | 팀색 몸통 + 가죽색 모자 + 활 + 화살 |
| 석궁수 | 가로 활대 **T자** | 팀색 몸통 + 강철 투구 + T자 석궁 |
| 경기병 | 갈색 말 타원(세로로 김) | 갈색 말 + 팀색 기수 + 사브르 |
| 중기병 | **회색 마갑** 말 + 초장신 랜스 | 강철색 말 + 팀색 기수 + 전장 랜스 |
| 궁기병 | 밝은 초원마 + 단궁 호 | 밝은 갈색 말 + 팀색 기수 + 단궁 |

공성병기(5종)는 32×32~48×48: 나무색 사각 프레임 기반(사다리=가로 레일 2줄, 공성탑=큰 사각+윗면 판, 파성추=지붕 실루엣, 투석기=팔+바퀴, 발리스타=가로 활대). 지형·성벽도 동일하게 코드 생성(타일 = 노이즈 섞은 단색, 성벽 = 회색 블록 + 흉벽 점선).

프리뷰 목업: `scratchpad/sprite_preview.py` (파이썬) — 러스트 구현 시 동일 도형 명령을 이식한다.
